# Organic UI · Design System

Природная, мягкая дизайн-система на чистом CSS. Без зависимостей, без сборщиков. Просто подключи и используй.

## 🚀 Быстрый старт (CDN)

Самый простой способ начать — подключить файл стилей напрямую через jsDelivr.

**Скопируйте эту строку и вставьте в `<head>` вашего HTML-документа:**

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/zephyr-m/organic-desing-system@master/organic.css">
